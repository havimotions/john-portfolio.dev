# John Ponteres Portfolio — V1

A static, responsive recruiter-first portfolio for software development and web development job applications.

## Included
- `index.html` — main portfolio homepage
- `styles.css` — responsive design system
- `script.js` — mobile menu, reveal animations, copy-email interaction
- `projects/lemoncraft.html` — LemonCraft Platform case study
- `projects/lemonfullreset.html` — LemonFullReset case study
- `projects/lemonbridge.html` — LemonBridge case study
- `case-study.css` — shared case-study styles

## Before publishing
1. Replace `john.ponteres@example.com` in `index.html` with your real professional email.
2. Add GitHub, LinkedIn, and résumé links once you decide which profiles/files to make public.
3. Replace the stylized project previews with real screenshots when available.
4. Only expose public source-code links. Many LemonCraft repositories are currently private.

## Local preview
Open `index.html` directly, or run a local server:

```bash
python -m http.server 8080
```

Then visit `http://localhost:8080`.

## Deployment
Because this version has no build step or dependencies, it can deploy to GitHub Pages, Cloudflare Pages, Netlify, Vercel, or any normal web host.
