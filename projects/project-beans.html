Project Beans

A custom WordPress/WooCommerce storefront built around a real coffee-product ordering flow, including responsive product browsing, cart behavior, shipping and billing steps, payment instructions, and custom admin functionality.

01 · THE PROBLEM

A normal storefront wasn’t enough.

Project Beans needed a coffee-shopping experience that felt simple for customers while supporting a less typical order flow. Shipping needed to be confirmed before payment, so the website had to communicate that clearly without making the product and cart experience feel confusing.

02 · THE SOLUTION

A custom WooCommerce experience around the actual buying process.

I built a responsive WordPress/WooCommerce foundation that keeps standard commerce behavior where it helps, while adapting the presentation and workflow around Project Beans’ ordering requirements.

ProductsResponsive product browsing and product-detail experiences
CartLive AJAX cart updates and order-state feedback
CheckoutShipping, billing, confirmation and payment-instruction flow

03 · WHAT I BUILT

Frontend and backend work in one project.

  • Responsive homepage, product browsing, product pages, cart, order, billing, shipping, confirmation and payment-instruction screens.
  • Live AJAX cart updates so quantity and cart state can change without unnecessary page reloads.
  • Product galleries and reusable visual components for a more consistent storefront.
  • Keyboard and focus-state accessibility improvements for interactive elements.
  • Custom WordPress functionality for content, validation, taxonomy/REST support and admin workflows.

04 · CHECKOUT WORKFLOW

Designing around shipping confirmation before payment.

The most important UX constraint was making the order sequence understandable. The site reinforces that shipping is confirmed before payment, then guides the user through product selection, cart review, customer details, shipping/billing information, confirmation and payment instructions.

05 · IMPLEMENTATION DETAILS

More than a page-builder exercise.

WooCommerce customization

Adjusted the presentation and workflow around the brand’s ordering requirements instead of relying only on default templates.

AJAX behavior

Used dynamic cart interactions to make common shopping actions feel faster and more immediate.

Reusable UI

Kept typography, spacing, controls and product components consistent across the shopping flow.

Admin tooling

Built custom content and validation support so the site is easier to manage beyond the public-facing pages.

06 · WHAT I LEARNED

Good web development starts with the business workflow.

This project reinforced that a technically working checkout is not enough. The experience has to communicate what happens next, reduce uncertainty, work across screen sizes, and remain manageable for the people operating the site.
